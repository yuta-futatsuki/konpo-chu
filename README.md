📋 遊び方

画面にある荷物を、段ボール箱へ入れてください。

指でドラッグしても、荷物をタップしてから箱をタップしても操作できます。

すべて詰めたら、箱を封印して次の便へ。

一筋縄ではいかない荷物もありますが、仕掛けをよく観察してみてください。
